# Google Play Store Visual Assets — TruthPop

This directory contains the prepared graphic assets for Google Play Store publication of **TruthPop – Truth or Dare** (`com.vivescriptsolutions.truthpop`), published by **ViveScript Solutions LLC**.

---

## Directory Structure & Specifications

```text
/play_store_assets/
├── app-icon/
│   └── app-icon.png               # 512 x 512 px, 32-bit PNG, max 1MB
│
├── feature-graphic/
│   └── feature-graphic.png        # 1024 x 500 px, 24-bit/32-bit PNG
│
├── phone/
│   ├── phone-01.png               # 1080 x 1920 px (16:9 portrait) - Gameplay overview & Truth card
│   ├── phone-02.png               # 1080 x 1920 px (16:9 portrait) - Bilingual English & Bangla mode
│   └── phone-03.png               # 1080 x 1920 px (16:9 portrait) - Party turn picker & Family mode
│
└── tablet/
    ├── tablet-01.png              # 1920 x 1200 px (16:10 landscape) - Tablet party mode layout
    └── tablet-02.png              # 1920 x 1200 px (16:10 landscape) - Safety, categories & offline features
```

---

## Asset Metadata & Guidelines

1. **App Icon (`app-icon/app-icon.png`):**
   - **Resolution:** 512 × 512 pixels
   - **Format:** 32-bit PNG (with alpha)
   - **Design:** Playful 3D popped speech bubble with question and exclamation marks in neon pink, electric cyan, and golden amber on a solid `#4A148C` deep purple background.

2. **Feature Graphic (`feature-graphic/feature-graphic.png`):**
   - **Resolution:** 1024 × 500 pixels
   - **Format:** PNG
   - **Design:** Celebration party art with balloons, confetti, neon stars, and game cards highlighting the vibrant, social party atmosphere.

3. **Phone Screenshots (`phone/*.png`):**
   - **Resolution:** 1080 × 1920 pixels
   - **Format:** PNG
   - Demonstrates instant gameplay, bilingual switching between English and Bangla, player picker pass-and-play, and pressure-free card reveals.

4. **Tablet Screenshots (`tablet/*.png`):**
   - **Resolution:** 1920 × 1200 pixels
   - **Format:** PNG
   - Showcases multi-user party gameplay on larger screens such as 7-inch and 10-inch tablets.
